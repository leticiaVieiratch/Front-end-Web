# ⚙️ API Backend - Data e Hora

API REST desenvolvida em **Node.js** e **Express** que fornece a data e hora atual do servidor em formato JSON, com suporte a CORS.

---

## 🔗 Links

- **Produção (Render):** [https://api-back4.onrender.com/data-hora](https://api-back4.onrender.com/data-hora)
- **Status da API:** [https://api-back4.onrender.com](https://api-back4.onrender.com)

---

## 🛠️ Tecnologias

- Node.js
- Express
- CORS
- Deploy no Render

---

## 🚀 Execução Local

```bash
npm install
npm start
# Servidor disponível em http://localhost:3000
```

---

## 🔌 Endpoints

- `GET /` — Status da API
- `GET /data-hora` — Retorna data, hora e timestamp
