# Frontend Web - Consulta de Data e Hora

Interface web limpa e responsiva que consome a API backend de data e hora e exibe os resultados em tempo real na tela.

---

## 🔗 Aplicação no Ar

- **URL da Aplicação (Vercel)**: [https://apiprojeto-git-main-leticiavieiratchs-projects.vercel.app/](https://apiprojeto-git-main-leticiavieiratchs-projects.vercel.app/)
- **API Backend (Render)**: [https://api-back4.onrender.com/data-hora](https://api-back4.onrender.com/data-hora)

---

## 🛠️ Tecnologias

- **HTML5**: Estrutura semântica
- **CSS3**: Estilização moderna com gradientes e flexbox
- **JavaScript (ES6+)**: Consumo assíncrono via `fetch`

---

## 🚀 Como Executar Localmente

1. Certifique-se de que a API backend está em execução (`http://localhost:3000` ou utilize a do Render).
2. Abra o arquivo `index.html` diretamente em seu navegador, ou utilize uma extensão de servidor local como o **Live Server** no VS Code.

---

## ⚙️ Configuração da URL da API

O arquivo `index.html` está configurado para detectar automaticamente o ambiente:
- **Localmente**: utiliza `http://localhost:3000/data-hora`
- **Em Produção**: utiliza `https://api-back4.onrender.com/data-hora`

---

## ☁️ Deploy

A aplicação está configurada e hospedada na [Vercel](https://apiprojeto-git-main-leticiavieiratchs-projects.vercel.app/).
