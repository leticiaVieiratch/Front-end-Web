# 🖥️ Frontend Web - Consulta de Data e Hora

Interface web que consome e exibe em tempo real a data e hora fornecidas pela API backend.

---

## 🔗 Links

- **Aplicação no Ar (Vercel):** [Acessar Aplicação](https://apiprojeto-git-main-leticiavieiratchs-projects.vercel.app/)
- **API Backend:** [https://api-back4.onrender.com/data-hora](https://api-back4.onrender.com/data-hora)

---

## 🛠️ Tecnologias

- HTML5 & CSS3
- JavaScript (Fetch API)
- Deploy na Vercel

---

## 🚀 Execução Local

Basta abrir o arquivo `index.html` no navegador. A aplicação detecta o ambiente automaticamente (usando `localhost:3000` em desenvolvimento ou o Render em produção).
